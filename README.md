# msalzer06 / 扫雷分析器06

一个不依赖构建工具的扫雷程序，支持自定义棋盘尺寸、雷数、实时雷概率，以及从自定义残局开始。

[点击此处即可运行](https://waroku06.github.io/msalzer06/)

## 在 NixOS 上运行

项目带有一个最小 Nix flake，在项目目录执行：

```bash
nix run
```

然后打开 <http://localhost:4173>。也可以不使用 flake，临时进入 Python 环境：

```bash
nix shell nixpkgs#python3 -c 'python3 -m http.server 4173'
```

然后打开 <http://localhost:4173>。

## 使用方式

- 普通对局：设置行、列和雷数后开始新局。左键翻开，右键标记，也可以在侧栏打开标记模式。
- 雷概率：打开“雷概率透镜”开关后，未翻开的格子会显示基于当前数字约束的雷概率。简单局面使用精确枚举，复杂局面会显示快速估算值。
- 残局编辑：切换到“残局编辑”，用“设置数字”“设置空白”和“擦除”设计已经翻开的格子。开始残局时，程序会根据这些数字约束随机生成雷位；雷不需要在编辑阶段逐个指定。

程序完全在浏览器本地运行，不会上传棋盘或操作记录。
